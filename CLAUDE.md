# Andeen-Hagerling-2500A

LevyLab's LabVIEW driver for the Andeen-Hagerling AH2500A capacitance bridge. It is an Instrument Framework driver, a child of `Instrument.CBridge`, and also ships as a standalone application. Targets LabVIEW 2019 64-bit.

There is no README. Trust the `.vipb`.

## Reading the code

`.vi`, `.lvclass`, `.lvlib` and `.lvproj` files are binary. Use the `lvkit` MCP tools (`query`, `read_vi`, `diff`) to read them; `grep` and `cat` return nothing usable. The `.vipb`, `.vipc`, `.iss` and `build.cfg` are text and can be read normally.

## Products

| Output | Details |
| --- | --- |
| VI package | `build support\AH2500A.vipb` produces `Levylab_lib_AH2500A`, installed to `<user.lib>\Levylab\AH2500A`. |
| Application + installer | Build specs `AH2500A Application` and `AH2500A Installer` in `AH2500A (x64).lvproj`, wrapped by `build support\Inno.iss` into `builds\latest\AH2500A_<version>_Setup.exe`. Entry point is `Inst.AH2500.AppLauncher.vi`. |

## Building and releasing

- On the shared `build.bat` + `build support\build.cfg` flow (see `build-support`'s CLAUDE.md): `build.bat "<repo root>" [release|test]`. Use `test` for anything that is not a release.
- `APP_SPEC` and `INST_SPEC` in `build.cfg` must match the build spec names in the `.lvproj` exactly (`AH2500A ...`, with the A). A mismatch fails the application build after the VIP has already been built and the `.vipb` bumped, so the run looks half-successful.
- `Library_Version` in the `.vipb` is already the *next* build number; vipBuild bumps it during every build, including failed or `test` runs.
- Tags are bare versions (`1.4.4.14`). Tags up to `v1.4.0.8` have a `v` prefix.
- `<Release_Notes>` in the `.vipb` are not cleared after a release. Rewrite them before each build.
- `builds\build_vip.bat` is the old per-repo script generated by Patrick Builder (7-Zip installer flow). It is superseded by the shared `build.bat` and is not in version control.
- Commit `e701498` moved this repo to the Inno Setup installer; releases up to 1.4.4.14 used 7-Zip.

## Layout

- `src\AH2500\AH2500.lvlib`: low-level instrument VIs (`Open`, `Close`, `SINGLE`, `AVERAGE`, `BIAS`, `VOLTAGE`, `UNITS`, `SHOW STATUS`, `SHOW SPECIAL`, `RST`).
- `src\Inst.AH2500\Inst.AH2500.lvclass`: the Instrument Framework driver (`Process.vi`, `API\`, `Overrides\`, `Private\`, `Typedefs\`, `Inst.AH2500.AppLauncher.vi`).
- `src\Inst UI.AH2500\Inst UI.AH2500.lvclass`: front-end UI class.
- `build support\DSEG7Classic-Regular.ttf`: seven-segment display font shipped with the application.

## Dependencies

- `.vipb`: `levylab_lib_instrument_type >= 1.2.2.14` and `levylab_lib_levylab_instruments >= 1.15.13.55` (Instrument Framework). Framework 1.15.13 makes the base Handle GET/SET return error 5402 for unhandled parameters; check the overrides when upgrading.
